# MooMoo Local

Автономная браузерная игра по мотивам MooMoo.io, с самостоятельно написанной игровой логикой.

## Запуск
Откройте `index.html` в браузере. Интернет и установка зависимостей не нужны.

## Управление
WASD — движение, мышь — направление, ЛКМ/пробел — действие, 1–9 — выбор предмета, E — лечение едой, R — возрождение после гибели.

## Реализовано
Сбор ресурсов, разрушение объектов, Age и выбор улучшений, 4 вида оружия, стены, шипы, мельницы, турели, 13 автономных ботов, сражения, здоровье, возрождение и лидерборд.

## Ограничения
Это первая игровая версия, не точная копия MooMoo.io. Пока нет мультиплеера, кланов, магазина шляп, всех оригинальных предметов, сохранения прогресса и продвинутого поведения ботов. Оригинальные закрытые скрипты и изображения не включены.
